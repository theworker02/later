## Why acquisition beats greenfield

Reproducing `later` means rediscovering domain constraints, re-implementing architecture and edge cases, rebuilding tests/CI/packaging, and rewriting diligence materials already present in this repository. Buying the transferable IP is the faster path to a production-ready starting point.

## Product thesis

`later` is a local-first temporal runtime for plain Ruby. It persists scheduled operations in SQLite, recovers leased work after crashes, records execution history, and provides an expressive path from one delayed call to recurring jobs, events, futures, and validated workflow graphs.
